# 产品概览

## 定位

Mindora 面向需要快速组织复杂想法的 Mac 用户：产品经理、研究者、学生、创作者和咨询顾问。核心价值是本地文件可控、键盘编辑高效、画布视觉克制、原生窗口和无障碍体验。竞品启发：XMind 的结构表达、MindNode 的简约交互、Whimsical 的协作感；Mindora 的初期差异化是离线、透明文件格式及快速结构化编辑，不宣称已有协作或 AI。

## 场景与边界

典型任务为会议构思、论文框架、项目拆解和个人学习。MVP 只验证「新建 → 编辑多层节点 → 切换布局 → 保存 → 重开」；目标完成度见 PRD。多格式导出、复杂布局、跨设备同步和 AI 在 V1/V2 规划。商业模式假设为一次购买或基础免费加专业功能，须经用户研究验证。

## 成功指标（发布前目标）

首次创建并保存成功率 ≥ 95%；100 节点交互延迟 p95 < 100 ms；无数据损坏的 1,000 次保存恢复回归；Beta 用户核心闭环完成率 ≥ 80%。这些是验收目标，不是实测值。
