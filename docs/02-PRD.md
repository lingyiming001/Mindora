# 产品需求文档

## 范围与优先级

| 版本 | 必须完成 | 不包含 |
| --- | --- | --- |
| MVP | 文档新建/打开/保存、节点 CRUD 与层级、折叠、撤销重做、左右平衡/单侧树、缩放平移、自动布局、崩溃恢复验证、基础键盘与无障碍 | 附件、自由布局、AI、同步 |
| V1.0 | 主题、备注/标签、搜索、模板、Markdown/OPML 导入、PNG/PDF 导出、最近文件、属性面板、完善快捷键 | 实时协作、AI |
| V2.0 | 组织图/时间轴/鱼骨图、关系线/边界/概要、批量操作、更多导入导出、演示模式、iCloud 评估 | 无承诺的第三方格式完美兼容 |
| 未来 | AI、知识图谱、协作、移动端 | 需另行论证 |

当前代码仅覆盖 MVP 的一部分，具体见 README。优先级 P0 为数据正确与编辑闭环，P1 为生产效率，P2 为扩展能力。

## MVP 验收

1. 一份导图恰有一个中心主题；新增/删除/重命名节点后保存，重新打开内容与顺序一致。
2. 100 节点常规编辑无明显卡顿；1,000 节点可打开和导航。具体阈值见性能文档。
3. 撤销和重做覆盖所有结构与文字更改；关闭未保存文档由系统提示。
4. 非法版本、重复 ID、过深树和损坏 JSON 显示可读错误，不覆盖原文件。
5. 键盘可完成创建、移动选择、编辑、删除、保存；VoiceOver 可报读节点层级与状态。

## 假设与待验证

目标用户更重视本地文件而非团队实时协作；macOS 14 为最低版本；文档默认 JSON 容器。通过 8–12 名目标用户访谈与 Beta 数据验证。
