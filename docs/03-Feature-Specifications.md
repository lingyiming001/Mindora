# 功能规格

## 文档

新建生成 UUID、schemaVersion=1 与中心节点；打开先解码和校验再进入编辑器；保存写临时文件并由系统协调替换。用户主动复制文件可通过 Finder/另存为；文档内复制、重命名、删除管理在 V1 文件库阶段。当前 SwiftPM 使用 FileDocument，正式工程应启用系统 autosave 和版本浏览并验证崩溃恢复。

## 节点命令

`addChild(parentID)` 在子列表末尾插入；`addSibling(id)` 在同父列表后插入；中心节点按 Tab 添加子主题。删除中心节点禁用；删除分支连同后代，撤销一次恢复整棵子树。拖动跨父分支前应拒绝拖入自身子树。顺序由父节点 `children` 数组定义，移动是同一事务中的删除加插入。节点文本空白可暂存为「无标题」显示，保存时不强制非空。

## 快捷键目标

Tab 子节点、Return 同级、Shift+Return 换行、Delete 删除、方向键按布局邻近节点导航、⌘Z/⇧⌘Z 撤销重做、⌘F 搜索、Space+拖拽平移。文本框获得焦点时 Tab/Return/Delete 遵从编辑语义，命令路由不能拦截输入法组合。当前代码只实现部分命令，剩余为 MVP 验收缺口。

## 交互反馈

修改后标题栏显示系统编辑状态；结构命令选择新节点；非法操作保持原状并给非阻塞提示；长布局超过 150 ms 时显示进度且允许取消。异步任务结果必须检查文档修订号，防止旧结果覆盖新编辑。
