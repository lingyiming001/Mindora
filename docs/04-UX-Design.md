# 用户体验与交互设计

## 信息架构

主窗口由可收起导航区、主画布、可收起属性区和顶部原生工具栏组成。MVP 可先使用主画布与右属性区；文件管理、模板选择器和设置在 V1。默认让画布占窗口宽度 ≥ 70%；窗口窄于 900 pt 时属性区改为浮层。

## 核心流程

启动显示最近文档和「新建」；无最近文档时提供空状态说明。新建后中心主题被选中并进入编辑。Tab 建子、Return 建同级、双击编辑文字；编辑结束后布局刷新，选中保持。⌘S 保存，标题栏显示状态；打开损坏文件时保留原文件并说明可恢复选项。缩放以指针位置为锚点，适应窗口有 48 pt 安全边距。

## 状态与可达性

加载时只阻止依赖文档数据的操作；错误信息包含动作、原因、恢复路径。选中描边不能只靠颜色，VoiceOver 标签读出标题、深度、子节点数和折叠状态。键盘焦点清晰；降低动态效果时禁用位移动画；高对比度模式提升边线与文本对比。鼠标、触控板与键盘路径均需测试。

## 设计验证

原型测试任务：30 秒内新建 3 层结构、撤销删除、切换布局、保存重开。记录完成率、错误点及主观负担；未通过时先修正任务路径再添加高级功能。
