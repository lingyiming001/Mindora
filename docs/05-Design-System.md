# 视觉设计系统

## 原则与 Token

以系统语义色为基础，品牌强调色建议 `#5865D8`，需验证 WCAG 对比度；浅色画布 `#F8F9FB`、深色画布 `#17191F`。文字优先使用 `labelColor`/`secondaryLabelColor`，避免固定灰色导致深色失效。字号：正文 13 pt、节点 14 pt、标题 20 pt；SF Pro 与系统 Dynamic Type。间距 4/8/12/16/24/32 pt；圆角节点 12 pt、面板 10 pt；线宽 1.5–2 pt。

## 组件

根节点为强调色填充，普通节点为系统面板色；选中态 2 pt 高对比描边并有键盘焦点环。工具栏使用 SF Symbols 16 pt 与原生工具提示。按钮最小点击区域 28×28 pt，重要操作 32×32 pt。连接线采用圆滑三次贝塞尔，线色继承分支。阴影仅在浮层和节点卡片轻用。动画 150–220 ms easeOut，遵循 Reduce Motion。

## 布局

主窗口最小 700×460 pt，建议 1100×720 pt。属性面板 240–300 pt；工具栏控件分组不超过 5 个主要动作。空状态居中展示一句任务说明和一个主按钮。主题继承顺序：系统外观 → 文档主题 → 分支主题 → 节点覆盖。设计 Token 集中定义在 `DesignSystem`，当前原型仍使用系统默认色，品牌主题尚未实现。
