# 无限画布架构

当前画布为 `MindMapCanvasView: NSView`，通过 `NSViewRepresentable` 嵌入 SwiftUI。`CanvasViewport` 保存缩放和屏幕偏移：screen = world × scale + viewportCenter + offset；反变换用于命中检测。缩放范围 0.15–3，触控板捏合与 ⌘滚轮保持指针下的世界点不变。适应窗口保留 48 pt 边距。

布局仅在文档改变时刷新，平移缩放不重新测量节点。绘制按可见世界矩形跳过节点与边；当前遍历全部几何条目作裁剪，没有空间索引或局部布局。绘制、命中和原生编辑覆盖层使用同一变换，避免缩放后点击位置漂移。

点击选择，⇧/⌘点击多选；空白或 Space 拖动平移；拖动分支到节点上跨父节点移动，拒绝移动到自身后代。双击/⌘E/F2 创建 NSTextView 覆盖层；Return 提交、Shift+Return 换行、Esc 取消，输入法交由系统处理。覆盖层包含在画布无障碍子元素中。

下一步为脏区域重绘、空间索引、后台可取消布局与增量计算；性能达标前不宣称 10k 节点流畅运行。
