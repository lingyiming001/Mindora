# 布局引擎

输入为已校验树、布局类型、节点属性；输出为 `LayoutResult(frames,edges,bounds,visibleNodes)`。节点使用系统字体与样式字号动态测量，宽度 126–280 pt，文字换行与元数据增加高度。层级间距 76 pt、兄弟间距 22 pt。

一次后序遍历计算子树跨度，一次前序遍历放置节点，复杂度 O(n)、几何内存 O(n)。横向树按子树高度排列；组织结构按子树宽度排列。左右平衡按子树权重分边；单侧树向右或向左；折叠节点只保留自身和占位。

布局切换保持 ID、文字、同级顺序和选择状态，仅更新几何；布局结果不序列化。当前未缓存字体测量、未实现局部增量布局。1,001 节点在早期调试测试中的单次布局为约 31–32 ms，这不是性能基准或发布验收结果。后续按性能文档做 Release、多设备和重复采样测量。

逻辑图、时间轴、鱼骨图、自由布局仍在后续版本；新增布局必须复用测量和输出协议，并新增结构不重叠及稳定性用例。
