# 渲染系统

`CanvasRenderer` 是共享 AppKit/Core Graphics 绘制器，供交互画布和 PNG/JPEG/PDF 导出复用。层次为背景网格、曲线连接线、节点卡片、选择/拖放状态、原生文字编辑层。SwiftUI 负责周边界面，画布节点不再创建大量 SwiftUI Button。

横向边从父外侧中点连到子内侧中点；组织结构边从父底部连到子顶部；曲线采用两侧同轴控制点。颜色按文档主题 → 根分支配色 → 节点覆盖继承。节点显示优先级、进度、标签和备注标记，选择描边保持屏幕线宽。

画布按世界可视区域跳过无关元素，尚无四叉树或 R-tree。文本由系统字体排版，编辑使用 NSTextView 以支持输入法、选区、复制粘贴和原生文本撤销。无障碍元素报读层级、子节点数、折叠和选择状态；该能力仍待用户验证。

位图导出使用 2x 分辨率，像素总量上限 40 MP；过大的图建议 SVG/PDF。图像和矢量导出遵从当前折叠状态，文本与 JSON 导出包含完整树。SVG 独立生成路径与文本，字体由查看器的系统字体替代，可能有少量换行差异。
