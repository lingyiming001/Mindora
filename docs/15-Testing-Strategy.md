# 测试策略

本轮早期 19 项 XCTest 已通过，覆盖撤销选择、跨分支移动、批量删除、旧数据默认值、导入导出与布局。用户随后要求自行测试；新增资料库与最后的焦点修正后未再构建或运行测试。MVP 门禁需扩展：命令边界（根不可删、重复 ID、循环移动）、布局不重叠与确定性、版本迁移、损坏文件、保存重开、中文输入法及快捷键焦点。领域测试不依赖 GUI；文件测试使用临时目录和真实 FileDocument 编解码。

集成测试覆盖新建 → 三层节点 → 改标题 → 切布局 → 保存 → 关闭 → 重开并比较结构；UI 自动化覆盖键盘与 VoiceOver 可达性、窗口尺寸、深浅色。性能测试使用 100/1k/5k/10k 固定 fixture，禁止调试构建与背景负载干扰。兼容测试保存每个历史 schema fixture，迁移输出通过快照与不变量验证。

CI 建议使用当前 Xcode 与上一稳定 Xcode，先运行 `swift test`，再构建正式 App 与 UI 测试。测试失败阻断发布；性能波动超过基线 20% 需复测并分析。
