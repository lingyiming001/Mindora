# macOS 发布方案

发布形态优先 Mac App Store，是否提供直接下载版由商业和沙盒需求决定。正式工程需 App Bundle、文档类型与图标、沙盒文件读写权限、开发者签名、公证、隐私清单评估、版本号和更新说明。现已提供 Xcode App 工程与 entitlement 配置，但仍需真实签名、沙盒运行与发布验收；本地构建脚本使用 ad hoc 签名，不能直接作为商店分发版本。

Beta 门禁：所有 P0 用例通过；旧文件迁移和损坏文件提示通过；100/1k 性能达标；VoiceOver/键盘核心流程通过；至少 20 位外部测试者连续使用 2 周，阻断级问题归零。发布前保存可复现构建、源代码标签、测试报告、数据格式 fixture 和回滚说明。新版本只升级可迁移 schema；遇到新版本文档只读拒绝写回。通过 TestFlight Mac 分发 Beta，正式版按 Apple 当前政策复核商店条款与审查要求。
