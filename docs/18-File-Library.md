# 文件与目录管理

实现日期：2026-10-13。资料库版本已完成启动构建；最新单窗口工作台改动未构建或测试，按用户要求由用户验证。

## 左侧导航

侧边栏顶端固定显示“新建思维导图 ⌘N”。下方分为“文件”和“大纲”；文件页显示资料库搜索、收藏、目录树、最近打开和当前新建位置。节点搜索会切到大纲页，文件搜索只匹配目录与文件名称。

启动时显示文件夹资料库；点击文件夹会显示其内容并设为新建位置；点击导图通过 `WorkspaceStore` 在当前工作台打开。点击资料库根项可恢复在根目录新建。新建操作先保存当前编辑，再写入唯一命名的 `.mindora` 文件，然后在当前窗口打开；不会覆盖已有同名文件。

## 目录操作

- ⇧⌘N 或文件页的文件夹加号创建目录；不接受空名称、斜杠、冒号、控制字符、`.` 或 `..`。
- 右键支持重命名、移动到、创建副本、收藏、Finder 显示和移到废纸篓。
- 拖放只允许移动当前资料库内部条目；拒绝根目录、自身子目录和同名目标；外部导图用“导入现有导图到资料库”复制。
- 移到废纸篓可通过 Finder 恢复。已打开的导图需要先关闭再删除；包含已打开导图的文件夹需先关闭文档再移动或重命名。
- 单个已打开的文件移动/重命名使用 `NSDocument.move(to:)` 保持文档地址更新。
- 资料库仅展示 `.mindora` 文件和普通文件夹；隐藏文件与符号链接不显示。子目录扫描上限为 64 层。

## 存储与权限

默认目录：`Application Support/Mindora/Library`。使用菜单“选择资料库位置”可指定本机、外置盘或用户已挂载的文件夹；访问授权以 security-scoped bookmark 保存于 UserDefaults。资料库自身不提供云同步协议。切换位置不会移动原资料库文件。

目录树后台扫描，通过修订 token 丢弃过期结果。根目录文件事件、应用切回前台和管理动作结束会刷新；外部对深层目录的改动可通过刷新按钮主动更新。收藏以相对路径保存，当前资料库中的重命名与移动会更新相关路径。

## 文件归属

`Features/LibraryStore.swift`：扫描、授权、目录操作、原生文档打开。
`Features/EditorSidebar.swift`：文件/大纲切换、目录树、拖放与菜单。
`App/EditorCommands.swift`：⌘N、⇧⌘N、打开保存与编辑菜单。
`ImportExport/MapInterchange.swift`：导图编解码与安全限制。

单窗口切换与保存流程见 `docs/20-Single-Window-Workspace.md`。
