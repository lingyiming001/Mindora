# 快捷键

文件与菜单快捷键在原生菜单中显示；画布快捷键只在画布获得键盘焦点时处理。编辑文字时保留 macOS 文本输入与输入法行为。当前是代码实现说明，最后新增的目录操作未运行测试。

可从“帮助 → 键盘快捷键”、`⌘/` 或设置的“快捷键”页查看。设置入口为 `⌘,`，资料库工具栏也提供设置按钮。

| 操作 | 快捷键 |
| --- | --- |
| 新建思维导图，保存到左侧当前文件夹 | ⌘N |
| 新建文件夹 | ⇧⌘N |
| 打开导图 | ⌘O |
| 保存并返回资料库 | ⌘[ |
| 保存 / 另存为 | ⌘S / ⇧⌘S |
| 添加子主题 / 同级主题 | ⌘K / ⇧⌘K；画布中 Tab 也可添加子主题 |
| 插入网址 / 代码块 | ⌥⌘K / ⌥⌘C |
| 就地编辑 | 双击、⌘E 或 F2 |
| 就地编辑中换行 / 提交 / 取消 | ⇧Return / Return / Esc |
| 删除选中分支 | Delete |
| 按画布方向移动选择 | 方向键 |
| 多选 | ⇧点击或 ⌘点击 |
| 全选 / 复制 / 剪切 / 粘贴 | ⌘A / ⌘C / ⌘X / ⌘V |
| 创建主题副本 | ⌘D |
| 撤销 / 重做 | ⌘Z / ⇧⌘Z |
| 同级上移 / 下移 | ⌥⌘↑ / ⌥⌘↓ |
| 展开或折叠分支 | ⌘. |
| 搜索主题、备注、标签 | ⌘F |
| 命令面板 | ⇧⌘P |
| 导入 Markdown / OPML / JSON | ⇧⌘I |
| 适应窗口 / 定位当前选择 | ⌘0 / ⌘L |
| 显示隐藏侧边栏 / 属性 | ⌥⌘1 / ⌥⌘2 |
| 专注模式 | ⇧⌘F |
| 平移 | 空白拖拽、Space 拖拽或滚动 |
| 以指针为中心缩放 | 触控板捏合或 ⌘滚轮 |
