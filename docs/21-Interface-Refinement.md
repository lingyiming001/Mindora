# 界面布局整理 · 2026-10-14

本轮按用户要求优化现有原生应用布局。沿用“用户自行测试”的约束，没有运行构建、测试或界面验证；下面记录的是代码变更及设计意图。

## 参考与取舍

- [MindNode 大纲](https://www.mindnode.com/support/guides/outlining)：借鉴独立的大纲入口和清楚的节点层级；编辑器默认进入大纲导航。
- [MindNode 样式与画布](https://www.mindnode.com/support/guides/mind-map-and-canvas-styling)：借鉴把样式设置集中在侧栏的思路。
- [XMind ZEN Mode](https://xmind.com/user-guide/zen-mode-new)：借鉴减少界面干扰、保留主要编辑区域的方向；专注模式退出时恢复此前面板状态。

这些来源提供交互参考，实际界面沿用 Mindora 的原生组件、品牌色和已有文件管理方式。

## 工作台分工

资料库管理文件，编辑器组织思维，属性栏处理当前主题。新建导图的主入口保留在左侧；资料库标题区显示当前目录、文件数量和展示方式，不再叠加相同的新建按钮。

### 资料库

- 固定左侧宽度 224 pt，减少分隔栏自动扩张。
- 面包屑、23 pt 目录标题、数量说明形成层级；移除占空间的宣传式说明。
- 文件夹单独排列为紧凑行卡；导图展示实际内容缩略图。
- 缩略图在后台读取文件并计算布局；损坏或不可读文件显示“预览不可用”。
- 网格/列表切换保存于 UserDefaults，空目录仍提供清晰新建入口。
- 最近文件默认折叠，收藏、目录树和文件定位仍可使用。

### 编辑器

- 左侧默认显示大纲，仍可切到文件管理。
- 右侧属性栏默认关闭，用户点击“属性”打开。
- 宽窗口属性栏以 272 pt 停靠；窗口窄于 1080 pt 时属性栏覆盖在画布右侧，避免把画布压缩成窄列。
- 顶部保留导航、添加主题、外观、查找、属性和更多菜单；布局/配色收入外观菜单，导入导出集中到更多菜单。
- 底部只显示主题计数、保存状态和缩放控件。专注模式提供退出入口并恢复此前面板状态。

### 属性面板

“内容”包含标题、备注、标签；“样式”包含颜色、字号和恢复默认；“任务”包含优先级和进度。各组使用统一间距和语义色，去除面板底部重复的新增/删除按钮。

## 代码

- `DesignSystem/InterfaceStyle.swift`：面板宽度、语义色、轻量图标按钮和属性分组组件。
- `Features/LibraryHomeView.swift`：资料库布局、网格/列表、文件缩略图。
- `App/EditorView.swift`：画布布局、工具栏、响应式属性栏与状态条。
- `Features/NodeInspector.swift`：内容/样式/任务页签。
- `Features/EditorSidebar.swift`：侧栏密度、新建入口和最近文件折叠。
