# 设置与备份

设置入口：Mindora → 设置（⌘,），或资料库工具栏的齿轮按钮。

- 常规：新打开编辑器是否显示大纲、属性栏；保留原生自动保存机制。
- 主题与字体：应用深浅色外观即时生效并在启动恢复。主题、布局用于新建导图和模板；字号用于新建导图及新增主题，中心主题加 3 pt。已有主题样式不变。
- 文件存储：查看、更改资料库和打开 Finder，清除最近文件记录。更改资料库会保存当前内容，不搬移旧文件。
- 备份：默认开启，成功保存时最多每 5 分钟创建一份，每份导图默认保留 20 份。间隔可选 1/5/15/30/60 分钟，保留数量可设 1–100。设置只在实际保存时触发检查，并非定时器。
- 快捷键：按文件、主题编辑和导航分组展示，与帮助窗口共用同一视图。⌘/ 可直接打开帮助。
- 关于我们：版本、产品定位、本地数据说明和反馈建议。

## 备份规则

- 每次保存：每次成功保存（含系统自动保存）创建副本。
- 按间隔备份（默认）：成功保存时检查间隔，支持 1/5/15/30/60 分钟。
- 每天首次保存：按本机日历，每份导图每天首次成功保存时创建副本。
- 仅手动备份：只通过“立即备份当前导图”创建副本。

规则和最近备份时间持久化，重启不会重置间隔或每天一次的限制。自动规则均由保存触发，不是定时器；手动备份不受开关和间隔限制。

资料库扫描、收藏与最近打开排除当前备份目录。选择新备份位置时禁止与资料库重叠，选择资料库时禁止使用备份目录及其子目录。已有备份不删除或搬移。

## 备份与恢复

默认存放于用户应用支持目录 `Mindora/Backups`，按导图 UUID 分文件夹，文件名包含时间与随机 ID。备份保留有效的 `.mindora` 格式，先原子写入新快照，再清理超额旧副本。失败在设置页显示，原文档保存不因备份失败中断。

“立即备份当前导图”提交正在编辑的文字后备份当前内存内容，即使关闭自动备份也可使用。更改备份位置后不迁移旧副本，关闭备份不删除副本。恢复时打开备份文件夹，把需要的副本复制到资料库并重命名，再打开检查，保留当前文件避免覆盖。
