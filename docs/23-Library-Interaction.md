# 资料库交互与性能方案

## 交互规则

| 入口 | 行为 |
| --- | --- |
| 目录树箭头 | 仅展开/收起，不切换目录 |
| 文件夹名称 | 进入目录，展开父级路径 |
| 导图行或卡片单击 / 获得键盘焦点后 Return | 直接打开编辑器 |
| 右键操作 | 作用于右键所在条目，打开命令直接打开 |
| 收藏 / 最近打开 | 快捷入口，单击直接进入 |
| 折叠当前目录的父级 | 只改变树的展开状态，当前内容不变 |

浏览目录、选中条目、树展开状态和打开文档分别存储。反复点击当前目录不执行保存或扫描。返回资料库仍保存当前编辑；保存失败时保留原编辑器。

## 性能措施

- 资料库刷新串行执行，多次请求合并；120 ms 合并窗口，防止后台重叠递归扫描。
- 扫描结果检查根目录和备份位置，位置已切换则丢弃旧结果并刷新新位置。
- 根据扫描结果建立目录索引，访问当前目录无需遍历整树；导图数量随快照计算一次。
- 树搜索结果在搜索词或数据变化时更新，悬停/选择不重复全树过滤。
- 当前目录列表使用 LazyVStack；切换文件夹不主动扫描整个资料库。
- 缩略图串行解析，缓存最多 24 个文件、累计 20,000 个节点。扫描快照携带文件修改时间与大小，仅变化文件触发预览更新；未变化的缩略图不重启任务。刷新时保留旧预览直到新预览就绪，预览任务使用 utility 优先级。
- 新快照移除失效选择与展开路径，目录删除时返回根目录。

## 2026-10-19 响应优化

文件点击后后台读取、大小检查、解析与校验，加载提示允许取消。新请求、返回资料库和关闭窗口使旧请求失效；旧编辑在新文件加载失败时保留。初次编辑布局仍在主线程完成。

批量回退/前进先应用全部命令、校验候选文档，再统一发布一次文档与布局，避免每步触发重复界面更新和保存调度。搜索按查询/历史版本缓存，画布辅助信息按布局/视口/选择/编辑状态缓存。

验证：30项回归测试通过；安装版成功打开343主题导图。未测量打开速度前后对照；空闲采样未捕获卡死，文件协调及同步保存/备份阻塞仍需现场采样。
