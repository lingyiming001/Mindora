# 资料库交互与性能方案

## 交互规则

| 入口 | 行为 |
| --- | --- |
| 目录树箭头 | 仅展开/收起，不切换目录 |
| 文件夹名称 | 进入目录，展开父级路径 |
| 导图行或卡片单击 | 选中，显示高亮，不进入编辑器 |
| 导图双击 / 获得键盘焦点后 Return | 打开编辑器 |
| 右键操作 | 作用于右键所在条目，打开命令直接打开 |
| 收藏 / 最近打开 | 快捷入口，单击直接进入 |
| 折叠当前目录的父级 | 只改变树的展开状态，当前内容不变 |

浏览目录、选中条目、树展开状态和打开文档分别存储。反复点击当前目录不执行保存或扫描。返回资料库仍保存当前编辑；保存失败时保留原编辑器。

## 性能措施

- 资料库刷新串行执行，多次请求合并；120 ms 合并窗口，防止后台重叠递归扫描。
- 扫描结果检查根目录和备份位置，位置已切换则丢弃旧结果并刷新新位置。
- 根据扫描结果建立目录索引，访问当前目录无需遍历整树；导图数量随快照计算一次。
- 树搜索结果在搜索词或数据变化时更新，悬停/选择不重复全树过滤。
- 当前目录列表使用 LazyVStack；切换文件夹不主动扫描整个资料库。
- 缩略图串行解析，缓存最多 24 个文件、累计 20,000 个节点。按文件修改时间与大小失效，资料库刷新后重新检查缓存。
- 新快照移除失效选择与展开路径，目录删除时返回根目录。

## 待验收

本轮仅源码检查，按用户既有约束未构建、测试、UI 验证或性能测量。不能据此宣称达到工业级质量。

需要确认：单击/双击和 Return 的焦点行为、快速切换目录、刷新中更换资料库、外部文件变更、复制/移动/删除、保存失败恢复，以及大量文件下的内存和交互延迟。当前监听只覆盖根目录，外部子目录变化仍依赖激活应用或手动刷新；搜索仍为全树搜索，后续可按真实规模改为后台索引。
