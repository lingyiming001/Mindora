# 主题属性面板

属性栏宽 340 pt，以当前选择摘要、四个分组标签和分隔线组织内容。使用等宽选项、靠右对齐的开关与颜色选择器，减少嵌套卡片和冗余说明。

## 内容

主题文字、网址、代码块、图片与文件、备注和标签。内容仅修改当前主题；附件随导图保存。附件限制显示为简短状态，详细限制可悬停查看。

## 外观

- 水平左 / 中 / 右对齐，垂直顶 / 中 / 底对齐。新主题默认双向居中，已有文件的显式对齐设置保留。
- 10–36 pt 字号，粗体、斜体、下划线、删除线和文字颜色。
- 自动或手动宽高，宽160–1200 pt、高44–2400 pt；全文所需尺寸仍为下限，不截断内容。
- 预设与自定义主题色、背景色、独立边框颜色、0–6 pt 边框、虚线、0–28 pt 圆角和阴影。
- 恢复所选主题的全图默认样式。

纯文字节点在整个主题内垂直对齐；含链接、代码或附件时在标题区内对齐，不覆盖内容区。就地编辑复用绘制坐标。

## 任务

优先级、任务进度、负责人、开始日期、截止日期和逾期提示。日期按天设置，修改日期时自动调整另一端以保持开始不晚于截止。负责人可被主题搜索检索。画布信息行显示负责人和截止日期。清除任务信息会同时清除负责人和日期。

## 画布

结构与方向、主题配色、全图文字和全图节点外观。全图设置覆盖对应字段（含折叠主题），并写入 defaultNodeStyle 供后续新主题继承。单主题可再覆盖。

外观、任务支持多选批量编辑，每次操作作为一个命令撤销。面板展示当前主选主题的值。新字段兼容旧文件并随 JSON 保存；PNG/JPEG/PDF 使用画布绘制器，SVG 同步文字装饰、垂直对齐和边框颜色、虚线。

验证：构建通过；覆盖默认居中、垂直位置、属性读写、多选与撤销、旧格式读取及 SVG 样式导出的测试通过。内容、外观、任务页面已在应用中检查。
