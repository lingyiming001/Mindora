# 主题属性栏优化

属性栏宽度调整为 320 pt，增加当前主题摘要；内容、样式、任务分别分组，明确多选范围。

- 内容：标题、备注、标签，仅修改当前主题。
- 文字：10–36 pt 连续字号、粗体、斜体、自定义文字颜色。
- 外观：预设/自定义主题色、自定义背景、0–6 pt 边框、0–28 pt 圆角、阴影开关。
- 任务：四档优先级、任务跟踪开关、0–100% 精确滑块、五档进度快捷按钮。
- 样式和任务对全部所选主题生效，每次修改作为一个批量命令撤销；面板显示当前主题值，不将混合值伪装成统一值（提示文字说明）。
- 恢复默认样式、清除任务信息分别作用于当前选择。

新增样式字段为可选值，旧文件继续采用原默认值，JSON 保留新属性。布局和画布共用字体度量，PNG/JPEG/PDF 使用同一绘制器；SVG 同步颜色、字重/斜体、边框、圆角和阴影。缩略图同步主要颜色、边框、圆角及粗体，未模拟阴影和斜体。

尚未实现：附件、关系线样式、负责人/日期、字体家族、对齐方式。当前版本不宣称包含这些能力。

本轮仅源码检查和工程生成，按用户已有约束未构建、测试或界面验证。需验证旧文件读取、新属性保存重开、批量编辑撤销、粗斜体布局、颜色选择和各导出格式。

## 文字对齐

样式 → 文字排版支持左对齐、居中、右对齐，可批量应用和撤销。旧文件默认居中，设置随节点样式保存；标题、就地编辑、缩略图与PNG/JPEG/PDF/SVG导出同步。代码与网址分区继续保持便于阅读的左对齐。此更新未构建、测试或UI验证。

## 自动与手动宽度

节点可保存可选 width，存在时优先沿用；缺失时按原文显式换行中的最长行自动测量，自动宽度最多720 pt，超长段落软换行，全文不截断。样式页“主题宽度”可关闭自动模式，通过滑块/步进调整160–1200 pt，可批量应用与撤销；高度始终随内容计算。新建节点和模板默认左对齐，JSON旧文件缺失对齐字段继续居中，已有对齐保持不变。本轮未构建、测试或UI验证。

## 画布直接操作

选中主题后，外侧底角出现宽度手柄（左分支位于左侧，其他位于右侧）。拖动实时预览宽度、文字换行与连线，160–1200 pt；高度自适应全文。松开生成一次可撤销命令，Esc 取消，预览期间暂停自动保存，结束后再保存提交内容。双击标题或⌘E/F2就地编辑，输入框随内容增长并使用画布缩放字号；提交仍为Return、换行为Shift+Return、Esc取消文字修改。当前不提供任意固定高度，避免截断内容。本轮未构建、测试或UI验证。

## 二维拉伸与全图设置更新

底角手柄同时调整宽高，宽160–1200pt、高度44–2400pt，仍以全文所需高度为下限，不裁剪文本。“样式 → 主题尺寸”支持独立恢复自动高度。拖动保持一次提交/撤销与Esc取消，预览期间不保存。

“画布”页新增全图文字与主题样式：字号、对齐、粗斜体、文字色、背景色、圆角、边框、阴影。操作覆盖全图对应字段（含折叠节点），其他属性保持原值，并写入defaultNodeStyle供后续新节点继承；单主题可再覆盖，恢复默认样式取当前全图默认值。整次全图修改可撤销，同时恢复新节点默认设置。旧文档缺少新字段仍可读取。
