# 主题网址、代码与附件

在主题属性的“内容”页中添加：

- 网址：每个主题一个 HTTP/HTTPS 地址，缺少协议时按 HTTPS 处理；显式点击后打开默认浏览器。无效地址保留输入并提示，不自动访问。
- 代码块：每个主题一个代码块，可选择常用语言，等宽编辑、原文复制；不执行代码，当前没有语法高亮。
- 图片与文件：每个主题最多 16 项，单个文件最多 3 MB，全图附件数据最多 8 MB。原文件嵌入 JSON，移动导图不会断开引用。
- 图片以缩略图预览，文件提供另存导出及移除；不直接执行附件。导出由用户选择目标位置。

所有内容仅编辑当前主题；新增、移除与修改支持现有撤销命令和保存。画布通过“链接/代码/附件数量”标记提示，正文和图片在属性栏查看，不在画布完整展开。搜索匹配网址、代码与附件名。

JSON/.mindora 完整保留内容；Markdown 导出链接、围栏代码及附件名称，二进制文件需要从属性栏单独导出。Markdown 导入不承诺恢复结构化代码/附件，OPML 与图片/PDF/SVG 也不携带可恢复的二进制附件。

旧文件缺少新字段时按空值加载，文件整体编码后仍限制 20 MB。添加多文件先检查容量，成功后作为一次编辑提交，失败不添加部分内容。

本轮源码检查并重新生成 Xcode 工程，未构建、测试或界面验证。需验证图片预览、保存重开、导图移动后附件导出、撤销重做、容量边界、网址打开及 Markdown 输出。

## 紧凑入口更新

属性栏移除常驻网址输入和代码编辑框，显示两条紧凑入口及快捷键；备注默认折叠，去掉重复主题摘要和分组标签。⌥⌘K 插入/编辑网址，⌥⌘C 插入/编辑代码；插入菜单、右键菜单及命令面板同步。编辑窗口自动聚焦，先编辑草稿，保存时按原节点 ID 提交为一次撤销命令，取消不改文件。清空保存可移除内容。Return 不绑定插入操作。此更新未构建、测试或界面验证。

## 主题内渲染更新

链接、代码和每份附件在主题卡片内独立分区。链接显示地址并可点击打开；代码显示语言、行数及前7行，点击打开完整编辑；图片以有界缓存的下采样缩略图显示；文件显示名称，点击定位内容属性页。每区右上角 × 仅删除该内容，可撤销；属性栏也提供删除入口。几何信息由同一布局函数用于测量、绘制与鼠标命中，标题编辑区不会覆盖富内容。PNG/JPEG/PDF 与 SVG 同步富内容，导出不绘制删除按钮。本轮未构建/测试/UI验证。

## 完整文字显示修复

修复标题按多行测量却按单行省略绘制的问题：文字测量与绘制统一字符换行，取消 600 pt 测量高度限制。富内容按实际宽度计算高度，网址/附件名换行、代码显示全部行且长行换行，删除按钮保留独立空间；SVG 同步完整文本。长内容会形成更高的主题卡片，可平移/缩放查看。此改动未构建、测试或UI验证。
