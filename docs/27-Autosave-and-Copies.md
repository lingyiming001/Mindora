# 自动保存与另存副本

## 保存语义

- 新建导图直接位于资料库；打开外部文件时先复制到当前资料库目录，原文件不变。
- 已提交到模型的编辑停止约 800 ms 后保存；⌘S、切换导图、回资料库和退出立即保存。
- 画布内正在输入但尚未确认的文字、代码/链接弹窗中的未保存草稿不算已提交编辑；切换/退出会提交画布文字，弹窗草稿仍需按保存。
- 另存为先保存当前导图，再向用户选择的位置写独立 ID 的副本；不改变当前文档 URL、目录或安全范围授权。取消另存为不撤销当前导图的保存。

## 文件冲突

关闭 NSDocument 原地自动保存，统一由工作台调度。采用 NSFileCoordinator 协调写入、原子替换和内容摘要比对，并在成功写入后同步修改日期和清除脏状态。检测磁盘字节发生外部变化时，先在同目录创建“外部修改 UUID.mindora”副本，再写当前编辑；副本无法创建则不覆盖。失败提示保留内存编辑，用户可检查权限后重试。

自动保存后仍按既有规则备份。外部冲突副本与普通备份独立。另存为不允许覆盖当前或已打开文档；其他目标覆盖仍通过保存面板确认。

## 验证

本轮仅源码检查，未构建、测试或界面验证。待验证：新建自动保存、外部文件导入、取消另存为、继续编辑不改变副本、权限失败、外部修改保留、切换/退出保存、带附件文件及长文本保存。
