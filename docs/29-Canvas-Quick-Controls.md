# 参考界面的轻量操作优化

本轮只改既有操作入口，不新增文档字段或依赖。

- 主题属性增加“画布”页：四种已有布局以缩略图选择，当前布局描边选中；切换后适应窗口。
- 四套已有主题提供色板预览、选中标记，复用changeTheme，不覆盖节点自定义颜色。
- 页面包含适应窗口和定位主题，复用既有视口命令。
- 工具栏增加撤销/重做，按现有历史状态启用。
- 选中节点外侧出现“+”，直接添加子主题；左分支入口置左，其余置右，与折叠和宽度拖动手柄分开。
- 导出不绘制这些操作控件。

未修改现有文件格式、布局算法或引入外部组件。鱼骨/时间轴等新结构及其他高级功能不属于此次小范围更新。

已重新生成工程；按既有用户约束，未构建、测试或UI验证。待用户检查布局切换、色板、按钮位置、添加子主题和撤销/重做。
