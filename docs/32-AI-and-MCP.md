# AI 助手与 MCP

## 入口与模型

工具栏“AI 助手”、菜单“AI → 打开 AI 助手”，快捷键 `⇧⌘A`。在助手中输入要求，点击发送或 `⌘Return`；可停止执行、清空对话和查看逐项操作记录。

设置 → **AI 与 MCP** 支持多个模型配置与默认模型：

- 名称：用于切换模型。
- API 根地址：OpenAI 兼容的 Chat Completions 根地址，例如 `https://api.openai.com/v1`；本机 Ollama 为 `http://localhost:11434/v1`。
- 模型 ID：使用服务商提供的实际 ID，必须支持 tools/tool_calls；不预设可能失效的模型名称。
- API Key：点击“保存密钥”，保存在 macOS 钥匙串。本机无需鉴权的服务可留空。

默认不共享导图正文。开启“共享当前导图”后，助手可以读取主题内容、代码、链接和附件元数据。消息、工具定义、已授权读取的内容及工具结果会发送到所选模型服务。附件二进制不会发送给模型。对话只保存在内存，最近四轮作为模型上下文；更换模型、导图或共享选项时不复用旧模型上下文。

当前是非流式 Chat Completions；兼容网关和本机服务也须支持该协议。暂未实现 Anthropic/Gemini 原生协议、OAuth、Responses API 或流式逐字输出。

## 应用操作范围

内置工具通过现有模型与存储层执行，避免绕过应用校验：

- 导图：读取、批量添加、修改文字/备注/标签/任务属性/链接/代码/样式、完整结构替换、子主题/同级主题、移动排序、复制粘贴、删除、撤销重做。
- 页面：所有主题与新主题默认样式、字号、颜色、对齐、宽高、圆角和边框；布局、配色和已有模板。
- 富内容：原生图片/文件添加面板、附件导出与删除。
- 文件：新建/打开/保存/另存副本/导入导出、当前空间文件树、创建文件夹、重命名、复制、移动、收藏和回收箱。
- 工作空间：列表、新建、切换、图标/介绍等详情修改、移除登记，文件跨空间移动。
- 应用：外观、默认导图设置、备份规则/间隔/保留数量、立即备份、原生存储位置选择、视图和设置面板。

原生文件选择、重命名、导入导出、附件选择、工作空间移除确认等仍需要用户完成面板。工具会明确区分“原生界面返回”和已完成的直接操作，避免把取消面板误报为成功。AI 无法读取或修改模型密钥、AI 权限和 MCP 配置，也不提供任意 shell/系统操作接口。

导图修改使用撤销命令。完整文档替换要求先读取当前版本；期间文档变化则拒绝替换。既有附件按真实标识恢复二进制，非法结构、超限节点/附件或未知附件标识会被拒绝。文件路径限定为当前空间内非隐藏相对路径，不能操作空间根目录或越界。

## MCP

新增服务，填写并保存连接配置，使用“测试连接”初始化并读取工具列表；测试不会执行 MCP 工具。启用服务后，助手每轮读取其工具列表并交给模型选择。

**本地 stdio**：程序必须填写绝对路径。参数使用 JSON 数组，环境变量使用 JSON 对象，例如：

```json
["/path/to/server.js"]
```

```json
{"SERVICE_TOKEN":"在此填写你的令牌"}
```

程序直接启动，不经 shell 解释，不支持在命令栏输入整条 shell 命令。环境变量存钥匙串，继承宿主应用的环境。启用服务意味着允许启动该程序；只配置可信程序。

**远程 HTTP**：填写 MCP 端点与可选 Bearer Token，支持初始化/initialized、会话 ID、协议协商、工具列表分页和 tools/call，支持 JSON 及 SSE 格式响应。HTTPS 为默认要求；本机回环地址允许 HTTP。凭据不跨重定向传递。协议优先 `2025-06-18`，兼容协商返回的 `2025-03-26` 和 stdio 的 `2024-11-05`。不支持旧式独立 SSE 端点、OAuth、服务端采样/交互请求、资源/提示词浏览或自动重连。

MCP 调用始终逐次确认，包括服务名、工具名和参数。失败的服务不会阻塞未依赖它的对话；助手展示连接失败，不会声称该服务已经可用。

## 执行与取消

- 默认应用修改逐次确认，可手动关闭一般修改确认；MCP、删除、移除和回收操作始终确认。拒绝后结束本轮，不自动重试。
- 每轮最多16次模型往返、单次最多32个工具调用、最多128个工具；请求/响应和上下文有体积限制。
- 用户在等待期间切换导图、修改主题或改变选择，会停止旧上下文操作。模型完成的操作保留，可对导图修改使用撤销；文件移动和外部 MCP 操作不属于导图撤销范围。
- 停止、关闭助手或关闭主窗口均取消任务。URLSession 取消在途网络请求，HTTP MCP 尽力发送 `notifications/cancelled`；stdio 终止自有子进程，超时后结束未退出的子进程。
- 远程取消不等于事务回滚；MCP 服务可能已经完成外部操作。已经结束的应用操作不会因停止而回滚。

## 界面布局（2026-10-17）

- AI 设置分为“模型服务 / MCP 扩展 / 使用权限”，配置列表与详情分栏，仅编辑当前选中项；编辑配置与切换默认模型分开操作。
- 所有字段使用顶部标签、明确输入底色和边框，密钥单独保存并显示本地结果；删除配置需确认。
- 聊天窗口使用紧凑模型/共享导图栏、示例提示、右侧用户气泡、左侧助手回复、紧凑操作记录与内联操作确认。

- 发送采用 ⌘Return，支持停止与回复复制；超过 30,000 字禁用发送并显示计数。适配系统浅色/深色表面颜色。
